说明:
  1. 所有 RV32A 指令均为 R 型格式, opcode 固定为 0101111 (AMO 操作码)。
  2. funct3 字段固定为 010, 用于标识字 (W) 操作。
  3. aq (acquire) 和 rl (release) 是原子内存排序位, 共同编码在 funct7 字段的高两位。
     - aq=0, rl=0 : 无额外排序约束 (普通原子操作)。
     - aq=1, rl=0 : 获取 (acquire) 语义, 后续操作不能重排到该操作之前。
     - aq=0, rl=1 : 释放 (release) 语义, 之前操作不能重排到该操作之后。
     - aq=1, rl=1 : 顺序一致性 (sequential consistency) 语义。
  4. LR.W (加载保留) 的 rs2 字段固定为 00000, 其他指令的 rs2 为通用寄存器。
  5. 所有操作均针对内存中 32 位字 (对齐) 进行。
  6. SC.W (存储条件) 的返回值: 成功存储时 rd = 0, 失败时 rd = 非零值。
